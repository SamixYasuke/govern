# GOVERN_FE

Govern landing page for global payments and multi-currency card management. Hero headline "YOUR MONEY. ONE CARD. TOTAL CONTROL." with Download the app CTA (App Store / Play Store), followed by Meet the Govern Card, product features (card balance, add money, manage card, recents), The Clarity You Need carousel (spend globally, every transaction explained), Built for Scale / Trusted Worldwide awards, user testimonials, join/create account section, and footer.
